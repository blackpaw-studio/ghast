# Phase 5: Swift 6, Observation, DI — implementation plan

Spec: `docs/specs/2026-11-02-phase5-swift6.md` (if this plan and the spec disagree, the spec wins). Branch: `modernize/phase5-swift6`.

## Conventions
- Run `xcodegen` after any step that adds/deletes files or edits `project.yml`.
- `T="xcodebuild test -project Ghast.xcodeproj -scheme Ghast -destination platform=macOS"`. Targeted runs: `$T -only-testing:GhastTests/<Suite>`, run directly.
- Full suite, clean builds, snapshot sweeps: `heavy $T` with Bash `run_in_background`. Check `uptime` first; above ~30, run targeted checks only and run the deferred set at the step's last commit.
- New tests use Swift Testing. Existing XCTest files are edited in place, not converted.
- Emoji commit prefixes. Each commit compiles. The full suite is green at the last commit of each spec step.
- Shared test support (new, step 1a): `GhastTests/Support/TestDefaults.swift` provides `makeIsolatedDefaults() -> (UserDefaults, cleanup)` (suite `net.evancoleman.ghast.tests.<UUID>`, `removePersistentDomain` on cleanup). It also provides `makeTestRunnerService(runners:) -> RunnerService`, which uses isolated defaults plus a temp `runnersDirectory`.
- Never write to `UserDefaults.standard` or `~/.ghast/runners` from a test. Both currently happen: `removeAllLocalRunners()` on `.shared` wipes the host app's real runner list, and discovery scans the real `~/.ghast/runners`. The host has a leftover `Test` runner there.

### 1c. Composition root, views via environment, remove the remaining `.shared`
- `Ghast/GhastApp.swift`:
  - New `struct AppDependencies { runnerService, apiService, authService }` with `static func live()`.
  - `AppDelegate` holds the instance: `init()` builds `.live()` lazily, and `init(dependencies:)` is for tests. `NSApplicationDelegateAdaptor` requires `init()`, and the delegate needs the RunnerService for termination cleanup.
  - The `GhastApp` body passes `appDelegate.dependencies` to `ContentView` and injects `.environmentObject(runnerService)` and `.environment(\.gitHubAPIService, apiService)`.
  - `performRunnerCleanup` uses the injected service and does nothing if the dependencies were never built (test host).
- Signal handling: C `signal()` closures can't capture context, which is why they used `.shared`. Replace them with `DispatchSource.makeSignalSource` on `.main`, preceded by `signal(sig, SIG_IGN)`. The sources are retained by `AppDelegate`, and their handlers call `stopAllRunners()` and then `exit(0)`. This drops the async-signal-unsafe `print` and `Thread.sleep(0.5)`. The behavior is the same: runners stop, then the process exits.
- `Ghast/ContentView.swift`: `ContentView(authService:)` stores it with `@ObservedObject` for now. `AppState` stays view-owned (`@StateObject`). The `#Preview` uses mocks.
- Views switch from `@StateObject … = RunnerService.shared` to `@EnvironmentObject var runnerService: RunnerService`: LocalRunnersView (3), RunnerConfigurationView, AddRunnerView, RunnerLogsView, RepositoryDetailView (2). `GitHubAPIService.shared` in AddRunnerView and RepositoryDetailView becomes `@Environment(\.gitHubAPIService)`. Update the previews.
- Tests: snapshot tests and `GhastAppTests`/`IntegrationTests` inject `makeTestRunnerService()` with `.environmentObject` and inject `MockGitHubAPIService` wherever the view calls the API. `GhastAppTests.testPerformRunnerCleanup` uses `AppDelegate(dependencies:)` and now asserts the injected runner's status is `.stopped`.
- No new test for the composition root (wiring). It is covered by the snapshot suite and step 4's launch check.

## Spec step 2: `ObservableObject` → `@Observable`

### 2a. LogTailer (✨ test-first)
- Test first: new `GhastTests/LogTailerTests.swift`, `@MainActor @Suite(.timeLimit(.minutes(1)))`. All tests use a temp file, and there are no sleeps. Waiting goes through a helper `nextChange(_:)` built on `withObservationTracking` and a checked continuation; the time-limit trait is only a hang guard.
  1. `start()` publishes existing file content in `text`.
  2. Appending via `FileHandle` makes `text` contain the new line (await `nextChange`).
  3. After `await stop()`, the captured descriptor is closed (`fcntl(fd, F_GETFD) == -1`, `errno == EBADF`), and later appends don't change `text`.
  4. `start()` on a missing file creates it.
- New `Ghast/Services/LogTailer.swift`: `@MainActor @Observable final class LogTailer`.
  - `init(fileURL: URL, load: @escaping @MainActor () -> String)`. The view passes `runnerService.readRunnerLogs`, so placeholder text stays in one place.
  - Members: `private(set) var text`, `start()`, `reload()`, `stop() async` (resumes after the cancel handler closes the fd), and `internal private(set) var fileDescriptor` for the test.
  - The source runs on `.main`, the handler uses `MainActor.assumeIsolated { reload() }`, and the event mask stays `[.write, .extend]`.
  - Deinit: the source and fd live in a `final class FileWatch: Sendable` guarded by `Mutex` (Synchronization, macOS 15), so the nonisolated `deinit` can cancel it. Its cancel handler closes the fd. This avoids `isolated deinit`, which may need a newer runtime than 15.0.
- `Ghast/Views/RunnerLogsView.swift`:
  - Remove `fileMonitor`, `logFileDescriptor`, `refreshTimer`/`startAutoRefresh`/`stopAutoRefresh` (dead: nothing calls `startAutoRefresh`), and the `DispatchSource` code.
  - Add `@State private var tailer: LogTailer?`: create and start it on appear, `await stop()` on disappear, call `reload()` after clear/start, and render `tailer?.text`.
- Verify: `xcodegen && $T -only-testing:GhastTests/LogTailerTests -only-testing:GhastTests/RunnerLogsViewSnapshotTests`
- Commit: `✨ Add LogTailer and move RunnerLogsView file monitoring into it`

## Risks
- **runnersDirectory injection goes beyond the spec text.** I added it under the spec's "no test reads global service state". Without it, discovery pulls the host's real `~/.ghast/runners/Test` into fresh test instances. Veto here if unwanted.
- **Signal handling changes mechanism** (C `signal` → `DispatchSourceSignal`). It is not unit-tested. Add `kill -TERM <pid>` while a runner is running to Evan's laptop check and confirm the runner process dies.
- **Step 1 could change snapshots.** Views that used to call the real API through `.shared` now get the inert default. `.task` usually doesn't run before capture, but if a snapshot changes, inject `MockGitHubAPIService` set to the prior state rather than re-recording early.
- **`@Environment(T.self)` traps at runtime when nothing was injected** (same as `@EnvironmentObject` today). A missed injection in a test crashes that test instead of failing an assertion.
- **`foregroundStyle(.secondary)` is hierarchical, not `Color.secondary`.** Inside a parent with a custom foreground style it renders differently. The 4b diff check is the guard.
- **Swift 6 may surface Sparkle/AppKit callback isolation issues** beyond the spec's list. Each `@preconcurrency` needs its justification comment; anything structural gets escalated rather than suppressed.
- **`stopAllRunners` blocks the main thread with `Thread.sleep`** for up to about 1.1 s per runner at quit. That is existing behavior, left as is (out of scope).
