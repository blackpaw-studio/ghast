# Phase 5 — Swift 6, Observation, DI

Status: draft, awaiting Evan's approval (2026-11-02).

## Goal
Compile under Swift 6 language mode with complete concurrency checking, on
Observation instead of Combine `ObservableObject`, with no app-owned
singletons. No user-visible behavior change.

## Delivery
One branch (`modernize/phase5-swift6`), four ordered steps, at least one commit
per step, suite green at the end of each step. One review and one merge at the
end. Snapshots re-recorded once, in step 4.

## Step 1 — Singletons → dependency injection
- Remove `static let shared` from `RunnerService`, `GitHubAPIService`,
  `EnvironmentService`. Inits become internal.
- `RunnerService` takes its persistence store via `init` (a `UserDefaults`
  instance; production `.standard`) so tests use an isolated suite.
- `GitHubAPIService` becomes `@MainActor final class` (its only callers are
  main-actor; the mutable token stays an instance property).
- Composition root: `GhastApp` builds one instance of each service and
  injects it. Views receive services through the environment; the existing
  `\.gitHubAPIService` key stays. `GitHubAuthService` receives the API service
  through its existing closures/init, not `.shared`.
- `EnvironmentService` has no app call sites: drop `.shared`, tests construct
  it directly. Whether to delete the type is a follow-up, not this phase.
- Tests construct fresh service instances per test; no test reads or resets
  global service state.

## Step 2 — `ObservableObject` → `@Observable`
- `RunnerService`, `EnvironmentService`, `GitHubAuthService` (and its
  protocol), `AppState`, `CheckForUpdatesViewModel` become `@MainActor
  @Observable`. `@Published` removed.
- Views: `@StateObject` → `@State`, `@ObservedObject` → plain property /
  `@Bindable`, `@EnvironmentObject` → `@Environment(Type.self)`;
  `.environmentObject` → `.environment`. Tests updated to match.
- Delete RunnerService's Combine log stream (`logStreams`,
  `getLogStream(for:)`) — no production caller. The 3 tests using it assert on
  the runner's log file instead.
- Test subscriptions to `$x.sink` / `objectWillChange` become direct state
  assertions (or `withObservationTracking` where the test is about change
  notification).
- `CheckForUpdatesViewModel` observes Sparkle's `canCheckForUpdates` via
  `NSKeyValueObservation` instead of Combine `publisher(for:)`.
- New `@MainActor @Observable LogTailer`: owns the file-system source and
  file descriptor for a log file, exposes the current log text, closes the
  descriptor on stop/deinit, delivers callbacks on the main actor.
  `RunnerLogsView` only renders it; the View-struct `DispatchSource`/`Timer`
  state is removed. Unit-tested against a temp file (append → text updates;
  stop → descriptor closed), with no wall-clock sleeps.
- End state: no `ObservableObject`, `@Published`, or `import Combine` in
  `Ghast/`.

## Step 3 — Swift 6 language mode
- `SWIFT_VERSION: 6` for app and test targets in `project.yml` (complete
  checking is implied).
- Fix every diagnostic at its cause:
  - RunnerService process `terminationHandler` and `DispatchQueue` work hop
    to the main actor with `Sendable` value snapshots; no non-Sendable
    `Process`/runner captured across isolation.
  - `AppDelegate` is `@MainActor`; the `DispatchQueue.main.sync` /
    `assumeIsolated` dance is removed.
  - `ContentView.imageCache` becomes main-actor isolated.
- `@unchecked Sendable`, `nonisolated(unsafe)`, and `@preconcurrency` are
  allowed only with a one-line comment stating why it is safe.
- Zero warnings from the Swift 6 migration in a clean build.

## Step 4 — `foregroundColor` → `foregroundStyle`
- Mechanical replacement of all 253 sites. Re-record snapshots once (1x, on
  the build host) and check that the diffs are rendering-equivalent, not
  layout changes.

## Out of scope
Rate-limit handling, the 2x snapshot problem, appcast automation, sign-out
keychain-delete error, real-network tests in `GitHubAPIServiceTests`,
`URLSession.shared` in RunnerService/ContentView, deleting
`EnvironmentService`. (All tracked as follow-ups.)

## Done when
- Clean build in Swift 6 mode with no concurrency warnings; full suite green.
- `grep` for `static let shared`, `ObservableObject`, `@Published`,
  `import Combine`, `foregroundColor` in `Ghast/` returns nothing.
- Fresh-context review passed (concurrency reviewer, given the isolation work).
- Evan launches the build on his laptop (`xcode-remote run`): stored sign-in
  survives relaunch, the runner list loads, a runner starts and stops, and the
  log view tails live output.
